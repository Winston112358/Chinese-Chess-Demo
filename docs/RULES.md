## 实现的基本规则

棋盘为 9 列、10 行，棋子在交叉点上走动。双方各 16 枚棋子，红方先行，一次移动一枚棋子。落在敌方棋子的位置即吃子，不能落在己方棋子的位置。

| 棋子 | 走法和限制 |
| --- | --- |
| 帅 / 将 | 九宫内沿横线或竖线走一格。两将帅不能在同一列无子相隔。攻击判断包含飞将。 |
| 仕 / 士 | 九宫内斜走一格。 |
| 相 / 象 | 斜走两格，象眼必须为空，不能过河。 |
| 马 | 走日字；先直走方向紧邻的交叉点有棋子时，马腿被堵。 |
| 车 | 沿横线或竖线走任意格，路径不能有棋子。 |
| 炮 | 不吃子时沿直线移动，路径必须为空；吃子时与目标之间恰好隔一枚任意颜色的棋子。 |
| 兵 / 卒 | 未过河只能前进一格；过河后也可横走一格。始终不能后退、斜走或升变。 |

程序模拟落子后的棋盘，检查己方将帅是否受到攻击；任何导致己方将帅被攻击或将帅照面的落子都会被拒绝。处于将军状态时也使用相同检查，因此只能应将。攻击检测考虑炮架、马腿和象眼。

内部坐标从黑方左上角开始：`x = 0..8`、`y = 0..9`。红方前进为 `y - 1`，从 `y <= 4` 开始视为过河；黑方前进为 `y + 1`，从 `y >= 5` 开始视为过河。九宫列为 `x = 3..5`，黑方行 `0..2`，红方行 `7..9`。界面记录使用从 1 开始的坐标，翻转棋盘不会改变记录坐标。

## 明确留到后续的功能

- 将死、困毙、胜负和和棋的自动裁定。
- 长将、长捉、重复局面与自然限着等竞赛规则。
- 认输、求和、联机悔棋、计时、AI、棋谱存档和观战。

首版可完整按合法走法推进对局，但对局结果由双方确认。没有合法走法时界面不会弹出获胜提示；双方使用“重新开局”继续试玩。将军提示与将帅安全检查不等同于自动判胜负。
