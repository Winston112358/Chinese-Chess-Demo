# 走棋记录与终局复盘

更新日期：2026-10-04。规范记谱与复盘已包含在 0.5.8 源码和 Windows 便携版中。

## 着法与绝对坐标

每步记录同时显示执子方、规范中文着法、绝对坐标和被吃棋子。例如：

```text
红方 车一平六 · (9,6) → (4,6) 吃黑方马
黑方 马2进3 · (2,1) → (3,3)
```

纵线编号从各自右手边开始，红方用“一”至“九”，黑方用“1”至“9”。“平”后的数字是目标纵线；马、相（象）、仕（士）“进”“退”后也是目标纵线；车、炮、帅（将）、兵（卒）的直线进退记录格数。绝对坐标则固定从黑方左上角起，列为 1–9、行为 1–10；翻转棋盘不改变记录。

同路同类车、马、炮或两兵使用“前”“后”，以靠近对方的一枚为前。三兵使用“前”“中”“后”；四至五兵或两条各有多兵的纵线按自己右侧起、每列前至后的顺序编号。单独纵线上的兵不参与这种编号。黑方的位置序号仍用中文，例如“一卒平5”；士象在同一纵线上保留原路号，通过进退辨认。

记谱依据[《中国象棋电脑应用规范（二）：着法表示》](https://www.xqbase.com/protocol/cchess_move.htm)的中文纵线格式，常规着法也可参照[世象联正式赛谱](https://www.wxf-xiangqi.org/images/2022_Sarawak/2022_cn_17th_World_Xiangqi_Championships_Men_and_Women_Individuals_Game_Records_17_.pdf)。记录和 AI 建议共用记法，生成名称时使用该步落子之前的棋盘，避免移动后路号或前后次序改变。

## 复盘操作

同机双人、人机、局域网对局结束后，在终局弹窗或侧栏终局区域点击“复盘本局”。第 0 步是本盘初始局面；第 N 步表示第 N 次最终采用的落子之后。当前步在走棋记录中标出。

打开复盘时保持暂停，点击“播放”才开始自动走步；播放过程中调整间隔，会按新间隔重新等待下一步。

| 控件 | 行为 |
| --- | --- |
| 播放 / 暂停 | 按选定间隔播放，或停在当前步。 |
| 播放间隔 | 1 秒一步、2 秒一步或自定义 0.1–3600 秒。 |
| 回到开局 / 最后一步 | 定位到第 0 步或最终局面。 |
| 上一步 / 下一步 | 向后或向前查看一着。 |
| 回放进度 / 走棋记录 | 拖动进度条或点击某着直接定位。 |
| 从头播放 | 播完后从初始局面再播一次。 |
| 退出复盘 | 返回真实终局棋盘。 |

回放包含最终棋谱，悔棋撤掉的着法不会作为动作出现。认输、协商和棋、总时间或单步超时，以及所有自动终局均可复盘；结束原因不会被重新计算成另一种结果。没有落子的终局仍可查看初始局面。

复盘是本机查看，不改变联机房间或对手的界面，也不会触发 AI 落子；真实对局已经结束，计时维持停止。重新开局、切换对局或联机双方同意悔棋导致真实棋局更新时，自动退出复盘并清除待执行的播放；离开页面也会丢失当前回放。没有棋谱文件保存或导入功能。

## 复盘中的沙盘

先定位到想分析的一步，再点“进入沙盘”。播放立即暂停，沙盘使用当前回放局面的棋盘与行棋方。按正常规则推演，可用“沙盘撤销一步”连续撤销到进入时的基线。

沙盘存在时锁定播放、步骤及进度控制，避免移动基线。“退出沙盘”丢弃推演分支，返回原来的复盘步骤；需要继续回放时再次点击“播放”。推演中的吃子和记录只属于该沙盘，不会写回原棋谱、真实终局或联机服务器。

## 实现接口

- `web/move-notation.js`：`chineseMoveNotation(positionBefore, move)` 生成规范着法。
- `web/move-records.js`：`getMoveRecords(game)` 根据最终棋盘逆推每步之前的局面，返回 `{ ply, side, notation, coordinates, capture, text }` 数组；保留最终历史顺序，支持沙盘的任意初始局面。`formatMoveRecord(positionBefore, move, ply)` 格式化单条历史。
- `src/shared/replay.js`：`createReplay(game)` 接受已结束的棋局并创建独立快照；`replayGame(replay)` 返回当前帧的独立副本；`seekReplay(replay, index)` 和 `stepReplay(replay, offset)` 定位步骤。回放快照与真实棋局、沙盘棋局相互独立。

“残局模式（待定）”已预留界面入口，当前按钮禁用，题目、布局编辑、导入格式与胜负目标待后续确定。
