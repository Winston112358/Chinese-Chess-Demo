# 中国象棋 Demo

可在浏览器和 Windows EXE 中运行的中国象棋试玩版，支持同机双人与局域网房间。两端共用规则模块，联机时由房主的服务器校验所有落子。

## 现在可以玩什么

- 标准 9 × 10 交叉点棋盘、32 枚棋子、红方先行、双方轮流落子。
- 七种棋子的移动和吃子限制，包括蹩马腿、塞象眼、炮架、过河和九宫。
- 禁止吃己方棋子、将帅照面、自陷将军；被将军时必须应将。
- 选择棋子后显示合法落点，提供将军提示、棋盘翻转、吃子和走棋记录。
- 棋子使用随程序打包的行书小字库，黑方“砲”与其他棋子风格一致，按实际笔画范围居中。己方可操作棋子悬停时显示红色微光，选中后略微放大并抬起，落子前可换选其他棋子。
- 同机双人可悔棋；联机支持建房、加房、刷新恢复席位和双方同意后重新开局。

**暂不自动裁定胜负**：不检测将死、困毙、和棋、长将长捉、自然限着。不提供 AI、计时和存档；双方自行确认对局结束后重新开局。

## 网页试玩 / 开发

需要 Node.js **22.12 或更新版本**（推荐 24），以及 npm。

```powershell
git clone https://github.com/Winston112358/Chinese-Chess-Demo.git
cd Chinese-Chess-Demo
npm ci
npm start
```

浏览器访问 [http://localhost:3000](http://localhost:3000)。点击棋子，再点击落点即可走棋。默认是同机双人模式，没有电脑对手。

如 3000 端口被占用，可换端口：

```powershell
$env:PORT = "3001"
npm start
```

## Windows EXE

从源码运行桌面客户端：

```powershell
npm run desktop
```

在 Windows 上生成便携版：

```powershell
npm run dist:win
```

输出为 `dist/Chinese-Chess-Demo-0.1.3-x64.exe`。复制此文件到 Windows 电脑后即可运行，无需安装 Node.js。首次构建会下载 Electron 和打包工具。

EXE 内置服务器，默认监听 3000 端口；端口被占用时会自动使用其他空闲端口。实际可分享的地址在界面“本机可分享的局域网地址”中查看。

生成文件不提交到源码仓库；当前为未签名的开发试玩版，没有自动更新。

## 与好友局域网对弈

1. 房主启动 EXE 或执行 `npm start`，保持程序运行。
2. 房主点击“创建房间（红方）”，获得 6 位房间码。
3. 在“本机可分享的局域网地址”选择当前网络的地址，例如 `http://192.168.1.100:3000`。把地址和房间码告诉好友。
4. 好友连接同一局域网：可以直接用浏览器打开房主的地址；也可以启动自己的 EXE，然后将“房主的服务器地址”改为房主地址。
5. 好友输入房间码，点击“加入房间（黑方）”。双方连接后红方开始。

若 Windows 提示防火墙访问，请允许**专用网络**；不需要路由器端口转发。不同 Wi-Fi、访客网络或无线客户端隔离可能使设备无法互访。

断线时暂停落子。刷新同一页面会恢复席位；也可以点击“恢复上次房间”。席位凭证保存在该浏览器标签页的 `sessionStorage` 中，关闭标签页可能丢失恢复凭证。房间仅保存在房主内存里，服务器退出就会清空；双方都离线 30 分钟后房间过期。首版不允许第三人占用已有席位。

这是供可信好友局域网试玩的房间服务，使用 HTTP/WebSocket；没有账号系统或公网部署配置。

## 验证

```powershell
npm test
```

自动测试覆盖所有棋子的特殊规则、将帅安全、吃子与悔棋，以及两个 WebSocket 客户端的轮次校验、棋盘同步、非法请求、重连与重新开局协商。

## 代码结构

```text
src/shared/rules.js   棋盘、移动/吃子校验、将军检测与悔棋
src/server/           静态网页服务和局域网房间
src/desktop/main.js   Electron 客户端与内置服务器
web/                 网页界面（桌面客户端同样使用）
tests/               规则与联机测试
docs/RULES.md        基本规则、来源与首版范围
```

规则依据已查阅的 [Xiangqi.com 棋子规则](https://www.xiangqi.com/help/pieces-and-moves)与[棋盘及初始布局](https://www.xiangqi.com/help/board-and-set-up)，实现范围详见 [规则说明](docs/RULES.md)。字体衍生自 OFL 1.1 授权的 Zhi Mang Xing，来源、补字与生成方式见 [字体说明](web/fonts/README.md)。本项目源码尚未指定开源许可证。
