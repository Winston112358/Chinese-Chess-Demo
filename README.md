# 中国象棋 Demo

可在浏览器和 Windows EXE 中运行的中国象棋试玩版，支持同机双人与局域网房间。两端共用规则模块，联机时由房主的服务器校验所有落子。

## 现在可以玩什么

- 标准 9 × 10 交叉点棋盘、32 枚棋子、红方先行、双方轮流落子。
- 七种棋子的移动和吃子限制，包括蹩马腿、塞象眼、炮架、过河和九宫。
- 禁止吃己方棋子、将帅照面、自陷将军；被将军时必须应将。
- 自动裁定将死、困毙、将帅被吃与联机超时，显示获胜方并停止落子。
- 选择棋子后显示合法落点，提供将军提示、棋盘翻转、吃子和走棋记录。
- 棋子与“楚河”“汉界”可选择行书、楷体或草书，字库随软件打包，缺字逐字回退到自带楷体，无需电脑安装字体。字形按实际笔画范围居中；己方可操作棋子悬停时显示红色微光，选中后略微放大并抬起，落子前可换选其他棋子。
- 提供米白、青瓷、雾蓝、浅藕四组纯色配对，以及浅榉木、浅胡桃木两组浅木纹皮肤。房主与参与者各自选择，仅改变自己的显示；浏览器会保存字体和皮肤偏好。
- 同机双人可悔棋；联机支持建房、加房、刷新恢复席位和双方同意后重新开局。
- 房主建房前可分别设置红黑双方的总时间：10 分钟、15 分钟或自定义 0.1–180 分钟（最多两位小数）。

暂不自动裁定和棋、长将长捉、重复局面与自然限着，不提供 AI、认输、求和和存档。本机双人模式不计时；后续开发主要面向两台电脑的局域网对弈。

## 网页试玩 / 开发

需要 Node.js **22.12 或更新版本**（推荐 24），以及 npm。

```powershell
git clone https://github.com/Winston112358/Chinese-Chess-Demo.git
cd Chinese-Chess-Demo
npm ci
npm start
```

浏览器访问 [http://localhost:3000](http://localhost:3000)。点击棋子，再点击落点即可走棋。默认是同机双人模式，没有电脑对手。

在“棋局外观”中选择字体和皮肤，立即应用到棋盘，无需重新开局。外观选择不发送到房间，不影响对手；走棋、翻转、重新开局和重新连接均保留选择。偏好保存在本浏览器的 `localStorage` 中，按网页地址区分；无法使用本地存储时，本次选择仍然有效。

如 3000 端口被占用，可换端口：

```powershell
$env:PORT = "3001"
npm start
```

## Windows EXE

从源码运行桌面客户端：

```powershell
npm run desktop
```

在 Windows 上生成便携版：

```powershell
npm run dist:win
```

输出为 `dist/Chinese-Chess-Demo-0.2.0-x64.exe`。复制此文件到 Windows 电脑后即可运行，无需安装 Node.js。首次构建会下载 Electron 和打包工具。

EXE 内置服务器，默认监听 3000 端口；端口被占用时会自动使用其他空闲端口。实际可分享的地址在界面“本机可分享的局域网地址”中查看。

生成文件不提交到源码仓库；当前为未签名的开发试玩版，没有自动更新。

## 与好友局域网对弈

1. 房主启动 EXE 或执行 `npm start`，保持程序运行。
2. 房主选择双方各自总时间，再点击“创建房间（红方）”，获得 6 位房间码。
3. 在“本机可分享的局域网地址”选择当前网络的地址，例如 `http://192.168.1.100:3000`。把地址和房间码告诉好友。
4. 好友连接同一局域网：可以直接用浏览器打开房主的地址；也可以启动自己的 EXE，然后将“房主的服务器地址”改为房主地址。
5. 好友输入房间码，点击“加入房间（黑方）”。双方首次连接后红方开始，同时启动红方时钟。

若 Windows 提示防火墙访问，请允许**专用网络**；不需要路由器端口转发。不同 Wi-Fi、访客网络或无线客户端隔离可能使设备无法互访。

采用双方独立的限时包干，**不加秒**：只有正在走棋的一方消耗时间，合法落子后换钟；非法落子、选择棋子和请求重新开局均不停钟。服务器用单调时钟计算实际经过的时间，校验收到落子的时刻是否已超时，并自动在无人落子时判超时负。客户端倒计时只用于显示，不能修改服务器剩余时间。将死、困毙或超时后双方停止计时，重新开局须双方同意，沿用本房间初始时限。

开始后断线仍计时；仍在线的一方可完成自己的当前回合。刷新同一页面会恢复席位；也可以点击“恢复上次房间”，剩余时间不会重置。席位凭证保存在该浏览器标签页的 `sessionStorage` 中，关闭标签页可能丢失恢复凭证。房间仅保存在房主内存里，服务器退出就会清空；双方都离线的未开局或已终局房间保留 30 分钟，仍在计时的房间先判完超时再开始保留期。不允许第三人占用已有席位。

这是供可信好友局域网试玩的房间服务，使用 HTTP/WebSocket；没有账号系统或公网部署配置。

## 验证

```powershell
npm test
npm run benchmark
```

自动测试覆盖所有棋子的特殊规则、将帅安全、将死与困毙、吃子与悔棋，以及两个 WebSocket 客户端的轮次、棋盘与胜负同步、计时切换、超时边界、断线恢复和重新开局。

判负只检查当前局面是否有合法着法，不搜索后续多步：按棋子几何生成候选落点，找到第一着合法应对立即结束检查。联机判定在服务器完成，浏览器只校验单步走法；每秒时钟同步不重绘棋盘。`npm run benchmark` 可复测常见局面与无合法着法局面的判定耗时；本机实测及算法上界见 [性能验证](docs/PERFORMANCE.md)。

## 代码结构

```text
src/shared/rules.js   棋盘、移动/吃子校验、将军检测与悔棋
src/server/           静态网页服务和局域网房间
src/desktop/main.js   Electron 客户端与内置服务器
web/                 网页界面（桌面客户端同样使用）
tests/               规则与联机测试
docs/RULES.md        基本规则、来源与首版范围
```

规则依据已查阅的 [Xiangqi.com 棋子规则](https://www.xiangqi.com/help/pieces-and-moves)、[棋盘及初始布局](https://www.xiangqi.com/help/board-and-set-up)与世界象棋联合会[《世界象棋规则》](https://www.wxf-xiangqi.org/images/wxf-rules/2018_World_Xiangqi_Rules_Chinese_2018.pdf)，实现范围详见 [规则说明](docs/RULES.md)。字库衍生自 OFL 1.1 授权的 Long Cang、LXGW WenKai 和 Zhi Mang Xing，来源、逐字回退、授权与生成方式见 [字体说明](web/fonts/README.md)。本项目源码尚未指定开源许可证。
