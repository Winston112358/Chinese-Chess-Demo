# 中国象棋 Demo

一个支持浏览器和 Windows EXE 的中国象棋项目，计划让好友在同一局域网内联机对弈。

## 第一版目标

- 标准 9 × 10 棋盘与 32 枚棋子，红方先行、双方轮流落子。
- 正确限制七种棋子的移动、吃子及将帅安全。
- 提供同机双人对弈和局域网房间。
- 网页与 Windows 客户端共用规则代码。
- 先交付可试玩版本，不实现 AI、计时、复杂界面或自动胜负裁定。

## 项目方向

使用原生 HTML/CSS/JavaScript 编写棋盘，Node.js 提供局域网服务，Electron 包装 Windows 客户端。规则模块独立于界面与网络，便于测试和后续扩展。

仓库已初始化。运行方法、规则来源和首版限制将在实现完成后补充。

## 开发约定

- 使用 Node.js 22 或更新版本、npm 和 Git。
- 依赖与生成的 EXE 不提交到 Git。
- 不提交密码、令牌、个人环境配置和日志。
- 棋子规则与联机逻辑增加针对性的自动测试。

本项目尚未指定开源许可证。
